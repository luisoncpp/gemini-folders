* Prefer return-early instead of nesting.

* Don't make functions with more than 4 parameters.

* Don't use magic numbers

* When calling a function with a hardcoded `true` or `false` use comments to simulate named parameters.

* When calling a function with parameters after a hardcoded callback, use comments to simulate named parameters.

* Update documentation after any meaningful change

* Read docs/architecture.md before doing anything else
