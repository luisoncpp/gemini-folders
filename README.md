I'm pretty much clonning this extension [Gemini Projects](https://chromewebstore.google.com/detail/gemini-projects/okjjhdoncledadkchbbbcddpopbbgbic), I liked the idea but when I tried it, it didn't work for me(probably because I use Google Workspace). So I decided to make it myself, the whole code is new, but I'm aiming to achieve the same functionality.

Thanks to the original authors!

Current sidebar features include:

- Grouping Gemini conversations into custom projects.
- Renaming conversations from the project sidebar actions menu.
- Moving conversations between projects from the same actions menu.
- Removing conversations from all projects without opening Gemini's native menu.
